# Contribution Guide

Thank you for contributing to CodexRootAtlas. This repository is designed for offensive security practitioners, lab authors, and penetration testers.

## How to contribute

- Open an issue first for new lab ideas, tooling improvements, or process documentation.
- Submit pull requests with clear descriptions and examples.
- Keep documentation current; update `docs/` whenever a workflow changes.
- Write lab and tool documentation alongside any new code or configuration.

## Style

- Use clear, professional language.
- Use `markdown` for documentation and templates.
- Keep scripts POSIX-compliant where possible.

## Files and folders

- `docs/` contains methodology, reporting, and engagement guidance.
- `labs/` contains hands-on exercises and writeups.
- `playbooks/` contains repeatable offensive security workflows.
- `tools/` contains automation and container tooling.
- `engagements/` contains client-facing templates.

## Issues and reviews

- Label issues clearly: `enhancement`, `bug`, `documentation`, `lab`, `tooling`.
- Reviewers should verify that additions fit the pentest workflow and are reproducible.
