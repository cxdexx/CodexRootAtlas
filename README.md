# CodexRootAtlas

CodexRootAtlas is a professional offensive security repository designed for penetration testing, lab development, exploit research, and client engagement workflows.

## Repository layout

- `docs/` - pentest methodology, engagement workflows, reporting guidance, and process documentation.
- `labs/` - hands-on labs, vulnerable applications, and challenge writeups.
- `playbooks/` - structured recon, exploitation, post-exploitation, and reporting playbooks.
- `engagements/` - client-facing templates for scoping, NDAs, and executive summaries.
- `tools/` - container tooling, automation scripts, and helper utilities.
- `scripts/` - environment setup and repository automation.
- `security/` - compliance policies, OWASP references, and security automation rules.
- `services/` - sample audit packages, engagement materials, and invoice workflows.
- `resources/` - cheat sheets, reference materials, and research notes.
- `archive/` - legacy or retired artifacts and backups.

## Getting started

1. Read `docs/README.md` to understand the pentest process and repo conventions.
2. Use `./scripts/bootstrap.sh` to initialize the lab structure and workspace.
3. Explore labs in `labs/phase-2-core-skills/` and begin with `web-app-local` exercises.
4. Review `playbooks/` for standard reconnaissance and exploitation workflows.
