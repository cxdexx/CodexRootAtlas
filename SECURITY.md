# Security Policy

CodexRootAtlas is a security-focused repository. If you discover a security issue within the repository itself, please report it responsibly.

## Reporting a vulnerability

- Contact the repository owner or maintainer.
- Provide a clear description of the issue and reproduction steps.

## Responsible disclosure

Do not publish any repository security issues publicly until they are fixed.

## Supported versions

This repository is maintained in its current structure as of the latest commit.
