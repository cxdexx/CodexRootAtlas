# Labs Directory

The `labs/` folder contains practical offensive security exercises and writeups.

## Structure
- `phase-1-foundations/` - networking, Linux, and Windows fundamentals.
- `phase-2-core-skills/` - web application and API exploitation labs.
- `phase-3-specialization/` - advanced topics such as Active Directory and containers.
- `platform-writeups/` - challenge and platform walkthroughs.

Use this directory for structured practice and to capture proof-of-concept work.
